#  Small Business CRM – Customer Relationship Management System

##  Project Overview

The **Small Business CRM System** is a web-based application developed to help small businesses manage their daily operations efficiently. It provides a centralized platform to manage customer information, services, billing, invoices, and business records.

The main goal of this project is to reduce manual work, improve business efficiency, maintain accurate customer records, and simplify billing operations.

##  Key Features

- **Customer Management:** Add, update, view, and manage customer details.
- **Service Management:** Manage business services and their pricing.
- **Billing Management:** Generate bills and manage customer transactions.
- **GST Calculation:** Calculate GST charges during billing.
- **Invoice Generation:** Generate and manage customer invoices and PDF receipts.
- **User Authentication:** Secure login and registration functionality.
- **Dashboard:** Access important business information from one place.
- **Business Record Management:** Maintain customer and transaction records efficiently.

##  Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to Project Folder

```bash
cd CRM-Project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

*Note: Installation commands may vary depending on your actual project configuration.*
